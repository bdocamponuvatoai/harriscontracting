# Colour palette

- Warm ivory canvas: #FBF9F5
- Deep slate headings, header and footer: #243449
- Muted blue secondary text: #5B6979
- Pale blue section backgrounds: #EDF1F5
- Muted bronze calls to action: #C5A27B
- Bronze hover: #DCC2A3
- Deep bronze active text and focus: #8D5A2E

Original company logo artwork and photography remain intact. Tokens live in `src/styles/base/tokens.css`; the remaining literal colours are in the partials that use them. The browser-tab icon (`src/app/icon.svg`) uses the slate and bronze.
